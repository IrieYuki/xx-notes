# 条目格式规范

## 文件骨架

```
# 标题
> 收集范围 + 「每条都是 签名｜返回｜备注 三格 + 真实输出示例」
## 怎么用这份文件         ← 格式约定、点链接跳转、顺序说明、允许重复的说明
## 索引 · 速查表          ← 目录 + 速查表合并，放最前
## 第一部分　内置函数       ### A1　类型转换 → #### 逐条
## 第二部分　容器方法       ### B1　list → …
## 学习建议
```

## 单条格式（逐条必须一致）

````markdown
#### `l.append(x)` 末尾追加一个元素

**签名** `l.append(x) -> None` ｜ **返回** `None`（原地修改） ｜ **备注** 把 x 当成**一个整体**加进去

```python
l = [1, 2]
l.append(3)          # [1, 2, 3]
l.append([4, 5])     # [1, 2, 3, [4, 5]]   ← 整个列表变成 1 个元素
```

> ⚠️ **返回 None**！写成 `l = l.append(3)` 会让 `l` 变成 `None`。想一次加多个元素用 `extend`。
````

规则：

| 位置 | 要求 |
|------|------|
| 标题 | `#### `名字(参数)` 一句话作用`；方法名带接收者前缀（`l.` `d.` `s.` `t.`）保证 slug 唯一 |
| 三格 | **签名 ｜ 返回 ｜ 备注**，固定顺序、固定全角 `｜` 分隔；没内容写「—」 |
| 备注 | 「什么时候报错 / 是否原地修改 / 等价写法」，一句话 |
| 代码块 | 可直接复制运行；`#` 后是**真实输出**；会报错的写法用 `# ❌ …` 注释掉 |
| ⚠️ | 只写真正的坑，没有就整行不写（别凑） |
| 段间 | 代码块后空一行再接下一条，避免渲染器粘连 |

## 索引表

```markdown
| 分类 | 用法（点击跳转） | 一句话作用 |
|------|------------------|-----------|
| A1 类型转换 | [`int(x, base=10)`](#intx-base10-字符串数字--整数可指定进制) | 字符串/数字 → 整数，可指定进制 |
```

- 每行**一个**函数 / 方法，不做「一行塞五个」的压缩表 —— 那样没法按条跳转。
- 分类列逐行重复，方便扫读和 grep。

## 锚点 / slug 规则

与 GitHub 一致，自己算，别猜：

```python
def slug(text):
    out = []
    for ch in text.strip().lower():
        if ch.isalnum() or ch in "-_":   # 保留中英文、数字、连字符、下划线
            out.append(ch)
        elif ch == " ":
            out.append("-")                # 空格 → 连字符
        # 其余标点（` ( ) 、 → 等）一律丢弃
    return "".join(out)
```

- 链接目标 `#<slug>`，slug 由**标题全文**（含一句话）算出。
- 想在 markdown-it 之类不生成标题 id 的渲染器里也稳，可在标题前加显式锚点
  `<a id="<slug>"></a>`，**id 必须等于上面算出的 slug**，两种机制才指向同一位置。
- 渲染后必须断言：索引里每个 `](#x)` 的 `x` 都在 slug 集合里。

## 分类顺序与重复策略

- 顺序**按日常使用频率**，并在「怎么用这份文件」里写出来（读者才知道怎么找）。
  实例：A1 类型转换 → A2 数学数值 → A3 聚合判断 → A4 序列迭代 → A5 排序筛选 →
  A6 类型属性 → A7 类与装饰器 → A8 字符串编码 → A9 输入输出 → A10 动态执行；
  容器：list → str → dict → set → tuple。
- **允许跨板块重复**（`in` 在 list / set / str 各写一遍，`pop` 在每个容器写一遍）：
  读者的路径是「从索引直接跳」，重复不增加阅读成本，但省掉来回翻页。
  必须在文件开头**明说这是故意的**，否则会被当成冗余、被要求去重。
- 极小的成对函数可合并成一条（`chr/ord`、`hex/oct/bin`、`globals/locals`），标题里都写出来。

## 生成方式（单一数据源）

条目写成 dict 列表 → JSONL 落盘 → 统一渲染：

```python
out = [HEAD]                        # 标题 + 怎么用
out.append("## 索引 · 速查表\n")      # 表头 + 逐行链接（slug 现算）
# 正文：part 变 → 二级标题；cat 变 → 三级标题；每条 → 标题 / 三格 / 代码块 / ⚠️
out.append(TAIL)                    # 学习建议
```

这样索引、正文、锚点三者永远自洽，不会出现「改了正文忘了改速查表」。
