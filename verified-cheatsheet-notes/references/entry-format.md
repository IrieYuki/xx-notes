# 条目格式规范（v2：解析 ｜ 操作 ｜ 提醒）

## 文件骨架

```
# 标题
> 收集范围 + 「每条都是 解析｜操作｜提醒 三段 + 真实输出示例」
## 怎么用这份文件         ← 格式约定、点链接跳转、顺序说明、允许重复的说明
## 索引 · 速查表          ← 目录 + 速查表合并，放最前（渲染器自动生成）
## A1 类型转换            ← 分类就是二级标题；条目是三级标题
## B1 list 列表
## 学习建议
```

## 单条格式（逐条必须一致）

````markdown
### `int(x, base=10)` 把字符串或数字转成整数

**解析**　把字符串或数字转成 int 整数；可以按任意进制读字符串。

| 参数 | 默认值 | 作用 |
|------|--------|------|
| x | 必填 | 要转的字符串或数字。字符串里不能带小数点 |
| base | 10 | 进制（2~36）。字符串带 0x/0o/0b 前缀时只能写 0 |

返回：int 整数

**操作**

```python
int("42")        # 42   ← 字符串转整数
int("1010", 2)   # 10   ← base=2，按二进制读
int(3.9)         # 3    ← 小数截断
```

> ⚠️ `int("3.14")` 会 ValueError——字符串带小数点先 `float()` 再转。
````

规则：

| 位置 | 要求 |
|------|------|
| 标题 | `### `名字` 一句话作用`；方法名带接收者前缀（`l.` `d.` `s.` `t.`）保证 slug 唯一 |
| 解析 | 先一句话白话「干什么」；有参数就接参数表（参数名 / 默认值 / 作用，逐项解释）；最后「返回：…」。没内容写「—」 |
| 参数表 | 三列 `\| 参数 \| 默认值 \| 作用 \|`；没有参数表的条目（组合写法类）直接跳过表格 |
| 操作 | 可直接复制运行；`#` 后是**真实输出**；会报错的写法用 `# ❌ …` 注释掉；多组示例之间空行 |
| 提醒 | 原「备注」合并进来：要点 + 易错点；没有就整行不写（别凑） |
| 段间 | 代码块后空一行再接下一条，避免渲染器粘连 |

Linux / 命令类笔记的差异：

- 同一命令的多个选项**合并成一条**（`ls` 的 -a/-l/-h/-t 都在 `ls` 一条里），一个命令一行索引；
- 参数表写选项（`\| -l \| 不写 \| 长格式：权限、属主、大小、时间 \|`）；
- `ops` 字段渲染**多组**（bash 块 + 真实结果 text 块）示例，一个选项一组，组间空行；
- 命令名里带 ` -x`、`--help` 这类写法进不了标题（见锚点规则），选项一律放参数表；
- 解析末尾加「**记：**」词源标注帮助记忆（用户要求）：`rm = remove`、`tar = tape archive`、
  `sudo = superuser do`、`grep = g/re/p（ed 编辑器的全局正则打印）`、`awk = 三位作者姓氏首字母` 这类；
  纯字面词（tree、kill、sleep）不用标。
- 参数表里的**选项同样能标**（用户要求）：作用列末尾加 `（记：a = all）`、`（记：r = recursive）`、
  `（记：f = force）`、`（记：h = human-readable）`、`（记：v = verbose）`；
  只标有助记忆的，`-name`、`-type` 这类字面词和「文件」「目录」这类位置参数不用标。

## 锚点 / slug 规则（双端兼容）

链接目标 = 标题全文的 GitHub slug：

```python
def slug(text):
    out = []
    for ch in text.strip().lower():
        if ch.isalnum() or ch in "-_":   # 保留中英文、数字、连字符、下划线
            out.append(ch)
        elif ch == " ":
            out.append("-")                # 空格 → 连字符
        # 其余标点（` ( ) 、 → 等）一律丢弃
    return "".join(out)
```

**双端规则（v2，防止 Obsidian 死链）**：用户用 Obsidian + gfm-heading-links 插件看笔记，
插件会把连续空白和连续连字符都压成一个 `-`（GitHub 每个空格变一个 `-`）。所以：

- 标题里**禁止空格包标点**：` → `、` / `、` ↔ `、` = [...]`、`命令 -x`、`--help` 都会让两边算出的锚点不一致；
- 改法：箭头贴字写（`字符串/数字→整数`）、`min() / max()` 写 `min()、max()`、命令选项并进正文参数表、
  `d[key] = value` 写 `d[key]=value`；
- 渲染器对每个标题断言 `slug(标题) == plugin_slug(标题)`，不相等直接报错退出 —— 死链进不了笔记；
- 渲染后还要断言：索引里每个 `](#x)` 的 `x` 都在 slug 集合里。

## 分类顺序与重复策略

- 顺序**按日常使用频率**，并在「怎么用这份文件」里写出来（读者才知道怎么找）。
  实例：A1 类型转换 → A2 数学数值 → A3 聚合判断 → A4 序列迭代 → A5 排序筛选 →
  A6 类型属性 → A7 类与装饰器 → A8 字符串编码 → A9 输入输出 → A10 动态执行；
  容器：list → str → dict → set → tuple。
- **允许跨板块重复**（`in` 在 list / set / str 各写一遍，`pop` 在每个容器写一遍）：
  读者的路径是「从索引直接跳」，重复不增加阅读成本，但省掉来回翻页。
  必须在文件开头**明说这是故意的**，否则会被当成冗余、被要求去重。
- 极小的成对函数可合并成一条（`chr(i)、ord(c)`、`hex(x)、oct(x)、bin(x)`、`globals()、locals()`），标题里都写出来。

## 生成方式（单一数据源）

条目写成 dict 列表 → JSONL 落盘 → 统一渲染：

```python
# 每条：{kind, cat, name, one, desc, params: [[名, 默认, 作用], ...], ret, code, warn?, out?}
# Linux 命令类：ops: [{code, out}, ...] 渲染多组示例
out = [HEAD]                        # 标题 + 怎么用
out.append("## 索引 · 速查表\n")      # 表头 + 逐行链接（slug 现算）
# 正文：cat 变 → 二级标题；每条 → 标题 / 解析 / 操作 / 提醒
out.append(TAIL)                    # 学习建议
```

这样索引、正文、锚点三者永远自洽，不会出现「改了正文忘了改速查表」。
