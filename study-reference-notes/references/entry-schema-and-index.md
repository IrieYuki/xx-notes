# 速查笔记：条目 schema、锚点算法与渲染契约

大改（重排 / 统一格式）时用来自动生成正文和索引，避免手抄 100 多条时前后不一致。

## 记录 schema（每条一个 dict，一行一条 JSON 追加到 jsonl）

| 字段 | 内容 |
|---|---|
| `part` | `A`（内置函数） / `B`（容器方法） |
| `cat` | 分类名，形如 `A1　类型转换`、`B3　dict 字典`（全角空格分隔编号与名字） |
| `name` | 标题里的名字，带参数：`int(x, base=10)` / `l.append(x)` / `a.issubset(b)`；互为反操作的合并写 `chr(i)、ord(c)` |
| `one` | 一句话作用（会有 `→`、`｜` 之外的标点没关系，但别带 `|` 和换行） |
| `sig` | 签名，含反引号 |
| `ret` | 返回什么（方法写「`None`（原地修改）」） |
| `note` | 备注：报错类型 / 等价写法 / 是否原地改；没内容写 `—` |
| `code` | 示例正文，不含围栏；`#` 后写真实输出，会报错的写法注释掉并标 ❌ |
| `warn` | 可选，⚠️ 要点；为空则整行不渲染 |

分类顺序（渲染时按这个顺序分组，条目按写入顺序）：
`A1 类型转换 / A2 数学与数值 / A3 聚合与判断 / A4 序列生成与迭代 / A5 排序与筛选 /
A6 类型与属性 / A7 类与装饰器 / A8 字符串表示与编码 / A9 输入输出与格式化 / A10 动态执行与反射 /
B1 list 列表 / B2 str 字符串 / B3 dict 字典 / B4 set 集合 / B5 tuple 元组`

## 标题与锚点

- 条目标题 = ``#### `{name}` {one}``；索引行的用法列就是它的链接。
- 链接 slug 必须等于渲染器**自动生成**的标题锚点，这样「HTML 锚点」和「标题锚点」两条路都能跳过去：

```python
def slug(text):
    out = []
    for ch in text.strip().lower():
        if ch.isalnum() or ch in "-_":   # 汉字 isalnum() 为真，要保留
            out.append(ch)
        elif ch == " ":
            out.append("-")
    return "".join(out)          # 其余标点（`、`（）、. / ｜ …）全部丢弃
```

- 渲染前 `assert` slug 全唯一（同名方法在不同容器下必须带接收者前缀）；渲染后核对「索引链接集合 ⊆ 条目 slug 集合」。
- 校验脚本 `scripts/verify_notes_examples.py` 会同时检查链接有效性、围栏配对、示例输出。

## 渲染顺序

1. 标题 + 一句话范围 + `## 怎么用这份文件`（使用说明、格式约定、章节顺序）。
2. `## 索引 · 速查表`：表头 + 每个分类逐行 ``| {cat} | [`{name}`](#{slug}) | {one} |``。
3. `## 第一部分　内置函数（直接写名字调用）` → 分类 `###` → 条目 `####`（签名行 / 代码块 / 可选 ⚠️）。
4. `## 第二部分　各类型常用方法（点号调用）` → 同上。
5. `## 学习建议`：高频函数清单、「方法原地改返回 None」规律、容器选择口诀、`isinstance`、推导式、别背签名。

## 追加新条目的最小改动

单条追加时不用整份重建：在对应分类末尾插入条目块，并在索引表同一分类的末尾加一行（顺序必须与正文一致）。
